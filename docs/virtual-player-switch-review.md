# 仮想プレイヤー: 話題を切り替える探索者

成人ノンバイナリー。ゲームや他漫画が好きで、好奇心はあるが不自然な反応には確認を返す。性別と性格を結びつけない。コード設定を先読みせず、実アプリの返答に応じて 6 回送信。実アプリのオフライン DB/ルール経路、模擬 DOM・仮想時間・文字アニメ圧縮。実 LLM、音、実ブラウザー、人間の楽しさは未検証。

実ログ: `virtual-player-switch-before.json`。

## 改善優先 3 項目

1. **自然な別れが受理されない。**「今日はここまで。弟さんにもよろしく、バイバイ！」に「フーン ツヅキ ハ アルノ?」。終了状態は false のまま、10 秒後に日本語ノートの自己開示を継続。退出の意図が通らず困る。
2. **自分で話した出身地を質問されると知らない扱い。** 自発的に「アタシ、スウェーデンのヨーテボリの近くで育ったの。」と言った直後、「へえ、ヨーテボリ生まれなの？ 今もそこに住んでる？」に「そこはまだよく知らないの。」「わかったふりで答えたくないな。」。本人の言葉を信頼しにくくなる。
3. **具体的に答えても再質問・突き放し。**「会場にはゲームもある？ 最近はゼルダが好き。」に好意的な「アタシモ スキ!」のあと「サイキン ナニニ ハマッテル?」。訂正して寄り道の楽しさを答えると入力の長いおうむ返しと「ソウイウ コトニ シテオクワ」。一緒に好きな話を広げたい気持ちが冷める。

## 良かった点・補足

- 初回も「最初から」も「はじめまして！」になった。
- 「ちいかわなら詳しいんだよね。ハチワレはどう？」には「わあ、その話うれしい!」からハチワレのご飯の感想につながり、好意が感じられた。ただ、その 10 秒後は弟の自己開示に切り替わり、ハチワレの話をもう少し続けたいと感じた。
- 「じゃあジョジョは？ ブチャラティが好きなんだ。」は「ジョジョ、スキ!?」のあと「そこはまだよく知らないの。」。拾った作品と本文の接続も弱い。
- 下書き「ちいかわなら」を入れて 20 秒待つと、6 秒後に旧返答の「わかったふりで答えたくないな。」が出た。継続入力は再現していないため、入力活動からの猶予か下書き非空の停止か、仕様との照合が必要。次のちいかわ送信後にジョジョの古い話題は出なかった。

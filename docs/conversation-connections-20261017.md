# ちいかわを受け取る／自然につなぐ（2026-10-17）

ユーザーの合格基準を明確化：①ちいかわの知識と、ワード・質問・感想・訂正を受け取れるか。②今の話を続け、接点を説明できる流れでちいかわへつなげるか。単語検出・知識量・歓声だけでは合格にしない。

## 再現と修正

実appのイベント処理を使うオフラインfixtureで、直接ちいかわを話す人／日常からつながる人の各8送信を固定して比較。タイミングは仮想、モデル・ブラウザ・人間の試遊ではない。

- 「ハチワレのどういうところが好き？」→料理知識へ逸脱していた。質問の言い換えを受け、気遣いへの本人の感想を返す。
- 「その気遣いがいいよね」→受験紹介に戻っていた。「気遣いがいい」に含まれるイガイを「以外」と誤判定。話題拒否と切り分け、気持ちの話を継続する。カタカナのチイカワから短いイカまで拾う問題も、同じ位置に重なる長い名前を優先して修正。別の位置に独立して書かれたイカは拾う。
- 「友達にあげるクッキーを作ったよ」→「よ」という創作名を記憶していた。明示された作品名・名前と日常の出来事を分離する。
- 友達が一緒に食べた報告→無知・料理紹介へ逸脱していた。実際のプレイヤーの発言から、友達への食べ物と一緒に食べた出来事を短い範囲で受け継ぐ。第三者の作ったもの、否定された出来事、助手が勝手に足した話をプレイヤーの体験としない。
- 写真が好きではない訂正、写真より友達の話をしたい希望を先に受け、写真好きの知識へ戻さない。
- 「どこからちいかわを思い出したの？」→「友達が一緒に食べてくれたところから」と接点を説明する。原作で同じ出来事があったとは言わない。モデルへも会話行為と、体験／本人の連想／原作の区別を渡す。良いモデル文は維持する。

例（オフラインの表示済み返答）：

> プレイヤー：少し焦げたけど、友達が一緒に食べてくれた
>
> えみちぃ：一緒に食べてくれたの、嬉しいね。
> 上手にできたかだけじゃなく、一緒の時間も大事にしてくれたのかな。
> そういう気遣いで、ハチワレを思い出しちゃった。

## 根拠と限界

フロント255件／中継71件合格。connection-fan-before/after-20261017.json、connection-bridge-before/after-20261017.jsonに同じ各8送信を保存。Luna mediumを明示指定した1人が保存された前後を限定レビューし、質問意図・訂正と希望・接点説明の主要3破綻の改善を確認。新規入力はrootが用意、レビュアーからの追加送信・外部通信なし。新しい主観プレイヤーを何人も走らせた報告ではない。実LLM通信は今回0回（前の429以降、再試行なし）。

現在の専門会話根拠は40項目。原作全体・最新連載・全グッズ・SNSの流行を網羅していない。今回の接点補助は友達への食べ物・一緒に食べる・写真という限られた日常の範囲で、一般的な意味理解をローカルだけで実現したわけではない。気遣いについての見方も本人の推測であり、友達の意図を断定しない。短い名前への歓声は既存のユーザー指示として維持するが、自然さの人間評価は残る。

次の評価も同じ基準を使う：知識の新規追加は「どんな質問に答えられるか・出典・限界・隣の話題」をひと組にし、会話の続きへ役立つものから確認する。未収録の細部は作らない。今回の限定改善だけで「完璧なファンbot」とは判定しない。

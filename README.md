# えみちぃ / Emmichy

17歳の欧米人、日本語学習中の文化オタクと約5分会話する非公式パロディ試作。ちいかわは大好きですが、まず相手の話を聞きます。原作コード・画像・音源・文字ROMは不使用。

## 起動・確認

Node.js 22以降。起動は追加パッケージ不要、テスト前に `npm ci`。`npm start` で http://127.0.0.1:1984 を配信。`npm test` で検証します。

本体は Draft PR #1 の `pilot-audio-readable-retro`。mainへの統合は試遊後です。公開試作: https://mukkii-game.github.io/emmichy/

## 会話

会話ネタの資料帳は [docs/fandom-sources.md](docs/fandom-sources.md)。2026-10-06確認の120件・27作品。ちいかわ32件、ジョジョ20件、HUNTER×HUNTER20件、ほか48件。ONE PIECEは自分から薦めない好み設定。AIにはサーバー所有の資料から最大5件だけ渡し、通信なしでも自作の感想文を使います。映画優先と連投防止、最近のカード回避、重大なネタバレの許可、期限付き報道を処理します。最新ニュースの自動巡回はしません。

資料の正本は `src/fandom.js`。更新時は同じ内容を `game-llm/games/emmichy-fandom.js` にコピーし、双方のテスト後に公開してください。ブラウザから資料やsystem promptは送りません。送るknowledgeは既知のカードID・作品ID・映画連続数のみです。

`src/config.js` の共通中継へ `{input,state,session}` を送ります。この作品はGemini → Groq → Workers AI（共通中継の既定順は変更せず）。画面下に応答元を表示し、通信失敗・上限・タイムアウト時はルール会話へ戻ります。`?nollm=1` は通信なしのモード。`auto` / `seed` / `replay` 指定もAIを呼びません。

キャラ設定と鍵は `mukkii-game/game-llm` 側だけ。ブラウザにはプロンプトを置きません。親しさ・熱量・口癖の演技状態はゲームが計算し、サーバーが数値を0〜5、口調を固定選択肢へ制限します。名前・好み・最近の会話も中継へ送られます。Gemini無料枠ではサービス改善に利用される場合があります。個人情報は入力しないでください。記憶はブラウザ内に最大40発言保存します。

固定開始は「ネエ Chiikawa ッテ シッテル？」。約5分か18往復で帰り、盛り上がった時は最大1分・2往復延長。入力中・IME変換中・返答中は切りません。終了は「アッ チイカワ 10カイメ ミニイク ジカン ダ！ マタネ！」。「コンニチハ」で再開、名前・好みは保持します。

ルール会話は自由な意味理解ができない縮退モードです。仕事・勉強・旅行・作品の話に対応し、何でもちいかわに変換する旧辞書は使いません。定番の短い挨拶・シーサーの心配・ストーリーや映画の感想は `src/curated.js` の用意した台詞。具体的な相談や質問・続きはLLM。AIは通常の日本語で返し、画面側がカタカナへ変換するため、音の誤りを演出にしません。名前・記憶・計算・終了もゲームで確定します。

保存した会話がある時は「続きから／最初から」を選べます。「最初から」は今回の会話を消し、名前・好みは保持。プレイ時間と回数もブラウザへ保存し、閉じていた時間を5分に含めません。

## 画面・音

人物496×672、8色ディザ。以前の248×168から絵の解像度を上げ、絵柄は維持。会話は全角カタカナ・分かち書きで、24pxのDotGothic16ドット書体を使います。漢字・ひらがな入力はそのままAIと履歴へ渡し、表示だけ同梱kuromoji/IPADIC辞書で読みへ変換。辞書は初回約18MB、以後ブラウザのキャッシュを利用します。未登録固有名詞は元の文字を残します。第三者ライセンスは `assets/vendor/`。BGM+SEは手動でON。WebAudioによるオリジナル生成音です。

`server.mjs` は残してあり、`EMMICHY_MODEL` 指定時のみ任意のOllamaを使えます。標準はローカルでも共通中継です。旧 `worker/` は削除済み。

調査は `docs/research.md`、画像条件は `docs/art-direction.md`、最新の検証と残課題は `HANDOFF.md`。

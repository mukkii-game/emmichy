# Claudeへの追加依頼：会話に使える具体的場面を補強

## 目的と前提

docs/chiikawa-research-brief.mdとresearch/chiikawa/codex-review.mdを読み、えみちぃが一つの人物・場面を掘り下げて話せる資料を追加してください。質問・人間の確認待ちは不要です。元のclaude.csv、Geminiの成果物、ゲームコードは変更しません。既存156行を全面的に調べ直す必要はありません。

推奨はSonnetのHigh。曖昧な因果や原作・アニメ・映画の差が最後まで解消しない場合だけ、少数の項目をOpusのMediumで独立確認する。使えなければ保留とし、有料APIや他モデルを勝手に追加しない。

## 作業

1. 同じIDで両CSVが重なる20件を比較し、話者、媒体、人物関係、曲の用途に食い違いがあるか確認する。同じIDに違う事実があるだけの場合は矛盾と決めつけず、主張ごとに比べる。
2. 具体的な場面を目標30件。日常・友情・失敗・頑張ること15件、食べ物5件、島の人物5件、本文が確認できる最近の漫画5件を目安とする。既存の場面をより確かな根拠で深めてもよい。アクセスできない範囲は別の場面で無理に件数を埋めず、未確認と報告する。
3. 各場面で「誰が／何をした」「関係する人物・物」「日常の気持ちや行動との接点」「えみちぃ自身の感想案」「混同してはいけない点」を元依頼の22列で整理する。原因や気持ちは本文に示された範囲に限り、独自の解釈は感想案へ分ける。
4. 場面の根拠は個別の公式原作投稿、公式動画、公式の文章によるあらすじ・発言など。動画を実際に確認した場合は本文位置へ時刻を記す。目次の題名、サムネイル、検索結果の短い文だけを場面本文の確認にしない。
5. 最新漫画は投稿ごとの内容を確認し、後の回で明かされた内容は後の回の根拠も記す。映画と原作で同じ場面だと推測しない。ネタバレを明記する。長い台詞・歌詞・漫画画像の転載はしない。

## 納品

- research/chiikawa/claude-scenes.csv：元依頼と同じ22列。目標30行。既存IDを使う場合は根拠の補強であることを報告する。
- research/chiikawa/claude-crosscheck.csv：固定列 `ID,判定,主張,根拠URL,注意点`。重複20件について1行ずつ。判定は `一致 / 補完 / 要修正 / 未確認`。
- 22列ファイルをscripts/check-chiikawa-csv.pyで検査する。実行不可なら未実行と記す。
- scripts/chiikawa-research-status.pyで実際の場面行数と「追加検品完了／未確認範囲」を追記する。

20件の比較を終え、確認できた場面を納品したら完了。本文にアクセスできず30件に届かなければ、確認できた分で完了し理由を残す。件数より再確認可能な根拠を優先する。最終報告は場面数・媒体別件数・食い違いの重要3点・検査結果だけを短く記す。Codexが統合する。

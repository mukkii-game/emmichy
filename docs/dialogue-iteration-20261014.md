# 専門会話の修正と完成までの状況

## 今回の変更

専門ターンでは、LLMがサーバー所有の根拠IDと短い感想・質問を一度の生成で選ぶ。事実文は検証済み資料から表示する。未知のIDや任意の事実文を採用せず、本人の感想・明示した想像は残す。旧fanRecoveryによる全置換は専門回答へ重ねない。感想文に混ぜた架空の合否・行動・特定の表情を除き、試験結果からの心情考察は「アタシの見方」として扱う。完全な事実判定器ではなく、未検出の言い換えや旧通常テキスト応答の余地は残る。

草むしり検定の受験・結果・お祝い・クッキー・アニメ話数を根拠別に追加。公式制作インタビューと報道によるあらすじの確認を区別。クッキーが手作りか購入か、点数や失敗の原因は資料から確定せず。research/chiikawa/exam-verified-20261014.jsonを保存し、全候補の無条件採用はしない。

質問中の作品名より質問対象の人物を選ぶ。具体的な追質問は現在の人物・場面から根拠を選び、実際に表示した事実だけを記憶する。「カワイイ!?」等の歓声は未回答質問にしない。詳しくないプレイヤーからの質問を拒否と解釈しない。日本語の勉強方法・スウェーデンの暮らし・おやつへの質問は固定設定から返す。同じ文を削り、質問中の性格を料理の話へすり替えない。

専門LLM待ち時間には短い合いの手を一つに限定。入力中に続き発話を止める既存機構を保持し、時計終了判定を待機質問より先に確認する。スマホの絵・文字サイズ・音の既存修正は保持。

期限付き公式話題2件（パークのクリスマス企画／強くなったハチワレのマスコット）を接続。受注終了を過去形で話す。2026-10-20を再確認期限とし、期限後は根拠として出さない。SNSの反響数は未取得なので大流行と断言せず、自動監視は追加していない。

- Sol6.1 mediumの限定出典調査1人、Luna mediumの仮想プレイヤー2人（ファン7送信／一般6送信）を使用。モデルは費用を抑えるため指定した。別Work・Relay・常時サブエージェントは作らない。

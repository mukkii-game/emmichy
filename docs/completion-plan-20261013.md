# Emmichy パイロット完成までの進行

## 完成の意味

正確なちいかわファンとして話せて、相手の言葉から一つの場面を深められる、また会いたくなるえみちぃを目指す。全ての漫画投稿や全SNSを収録することは完成条件にしない。知識の量、テストの本数、キャラの歓声だけで完成宣言しない。

## 作業順と通過条件

1. **会話の土台（進行中）**：人物/場面/問い/訂正/実際に話した内容を持つ。サーバー所有の少数の根拠でLLMが一人の話者として答える。旧ルールによる重複する候補注入・回答の全置換を減らす。話題変更・再開・入力中断・失敗時の範囲を機械検証。
2. **深い知識を作る**：草むしり検定と励まし、島/映画、人物/食べ物の3組を優先する。既存Claude/Gemini資料の出典を再確認し、主語/行動/対象/媒体/場面/考察/禁止混同を整理。知らない点を架空の場面で埋めない。検定の一次根拠不足を最優先で解消。SNS/ニュースは別の期限付き話題資料として関連するところだけ加える。
3. **人格とテンポ**：まず正確な専門回答を評価し、その同じ根拠へ喜び・好み・日本語の短い言い直し・固定したスウェーデンの本人設定を重ねる。今の問いを答えてから感想へ。長文を意味で分け、入力が始まったら続き発話を止める。長い待ち時間を別の話題の独り言で埋めない。
4. **会話して直す**：保存済み人間ログの失敗を再現。新しい主観評価はファン/一般プレイヤーの2人まで、各6〜8送信。同じ場面への二つの追質問・訂正・反復苦情・話題変更を入れる。指摘→修正→同じ入力で再試遊。実LLMは最大3プロバイダー呼出しの既存確認を使い429で止める。模擬/実生成/人間の感想を区別。
5. **Webの仕上げ**：スマホで顔/会話/入力を同時に見られること、BGM終了、開始/再開/時間表示、保存/消去、無料LLM失敗の遊び方を確認。表示済み会話の記憶はブラウザ保存を維持。サーバー全プレイヤー共有の学習はパイロットの必須条件にしない。ユーザー発言を未検証の原作事実へ自動昇格しない。
6. **人間の最終試遊**：検証済み修正はmain→Cloudflareへ即反映する既存許可に従う。候補のURL、変更、実例、残る制約を短く報告し、ユーザーに5分の試遊をお願いする。楽しいか/また会いたいかは人間評価で確認し、重大な破綻が残れば戻って直す。

通過基準：3組それぞれで6〜8往復、同じキャラ/場面を保持、訂正を受け止め、架空の場面を断言せず、同じ説明を繰り返さない。相手が別の話を希望したら応じる。原作を知らない人にも楽しめる語り方。表示・音・保存に遊べない不具合がなく、無料枠停止で入力が固まらない。模擬だけで人間の面白さを保証しない。

## 2026-10-13の実施

stage1の最初の実装：src/specialist.jsに根拠パケット、場面継続、既出事実、未収録の範囲を実装。appの表示済み文章から記録し、engineで保存を復元、sessionで新規会話を初期化。中継は同じ所有資料から再構成し、ちいかわ専門ターンの旧候補注入をまとめた。TVアニメOPと映画OPの混同を防ぐ。218フロント/56中継テスト合格。

残る制限：既出事実IDは全文一致で確認したものだけ。意味を言い換えた反復は直近の実会話もモデルへ渡して避けるが、完全検出ではない。既存のgroundModelReply/fanRecoveryによる全置換、未知の検定場面への回答、SNS資料の実行時接続、人間の楽しさ評価は完了していない。

Luna mediumの限定レビュー1人を使用。外部Claude/Geminiにはresearch/chiikawa/scene-research-request.mdの狭い場面調査を渡せる。人間が同ファイルを読んで作業するよう一度伝えればよい。現時点では外部への依頼を送信しておらず、実行中ではない。Director/実装/統合はこのWorkに残す。

公開実装の候補：LangGraph.js（https://github.com/langchain-ai/langgraphjs、MIT）とMicrosoft TinyTroupe（https://github.com/microsoft/TinyTroupe、公式README）を確認。前者の状態と記憶を分ける構造、後者のペルソナ評価は参考になる。ただし公開中の軽いWebゲームの会話・音・入力をそのまま完成させるものではなく、現段階で移植はしない。今回は外部コードの転載や依存追加は0。必要な部分を採用する時に、具体的なコード/ライセンス/運営費を確認する。

# 会話ネタの資料帳

確認日: 2026-10-06。120件 / 27作品（ほかにONE PIECEの好み設定）。

公式サイト、作者・声優インタビュー、報道、Wikiを短く要約。記事や漫画の台詞の丸ごとコピーではありません。会話のヒントはえみちぃ用に書いた創作の感想です。ファンWikiは非公式。報道されたファンの不安を公式の結末とは扱いません。

映画は優先しますが、明示された他作品が優先。同じカードを避け、一般的なちいかわ話では映画を連投しません。シーサーの9月の報道は10月20日までの話題資料で、今日の最新話を自動取得する機能はありません。重大なネタバレは明示された許可が必要です。

口癖はユーザー指定の短い改変と、自作の言い回し。長い台詞集にはしていません。島二郎と幼児向けのしまじろうは別人です。

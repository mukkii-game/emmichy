# Emmy調査とEmmichy設計メモ

調査日：2026-10-04。原作の実ディスクを入手・実行・逆アセンブルした調査ではない。以下は公開資料の確認と、それに基づく試作設計。

## まず版を分ける

初代Emmy（1984、PC-8001系）と、Emmy II（1984、PC-8801/FM-7系）、後発のMSX2版を混同しない。ユーザーの添付は金髪の人物・右下のEmmyロゴとII表記があるため、Emmy II系の画面を視覚基準とした。原画像は試作へ転載していない。

MAMEのPC-8801ソフト一覧にはEmmy II、1984年11月、BASIC V1が必要との識別情報がある。具体的な発売日を日単位では確定しない。

- [MAME公式・PC8801ソフト一覧](https://github.com/mamedev/mame/blob/master/hash/pc8801_flop.xml) `emmy2`
- [MAME公式・PC8801実装](https://github.com/mamedev/mame/blob/master/src/mame/nec/pc8801.cpp)：640×200、8色、8ドット文字幅など、描画方式の確認に使用。

## 会話と遊び

初代のプレイ検証記事では、語を空白で区切る、質問末尾に疑問符、終了はバイバイという入力方式を報告。未知語への聞き返し・反復学習らしき挙動、人称の置換、同じ話の反復への拒否、褒め言葉と反応の変化も報告されている。ただし二次資料であり、IIの正確なアルゴリズムや確率分布まで保証しない。

[レトロPC美少女ゲーム攻略wiki・Emmy](https://w.atwiki.jp/retropcgame/pages/393.html)

ゲーム保存協会はMSX2版について、辞書照合、初期語彙、ディスクへの会話学習、古い記憶の忘却を説明している。この説明をPC-8801版の辞書サイズ・内部実装にそのまま当てはめない。

[ゲーム保存協会・保存録0016](https://www.gamepres.org/2026/06/30/case0016/)

原作には成人向けの進行要素があったが、今回のユーザー指定のティーンには引き継がない。進行のご褒美は、記憶の発覚・感情の変化・とぼけのほころびとする。最後はアニメ・映画を観るために本人が会話を切り上げる。

## 面白さ／つまらなさ

当時の体験を振り返った記事は、噛み合わない返答のため、目的よりも「会話を成立させたい」ことに夢中になる点を指摘する。

[AKIBA PC Hotline!・80年代中期のアダルトソフト事情](https://akiba-pc.watch.impress.co.jp/docs/column/retrosoft/1401006.html)

以下は調査からの制作上の解釈。

| 残す面白さ | 避けたい退屈さ | Emmichyでの処理 |
|---|---|---|
| 通じた気がする瞬間 | 無関係な相槌の連発 | 話題を拾ってからちいかわへ脱線 |
| 機械に人格を感じる | 単なるランダム選択 | 名前・好み・矛盾・感情を保持 |
| 少ない絵の変化が意味を持つ | 褒め言葉の作業的連打 | 褒める意図を見抜いてとぼける |
| 未知の相手を探る | 攻略手順で機嫌を上げるだけ | 賢さとファンの弱点を発見する |

「賢いのにわざとバカ」と「好きすぎて本当に上の空」を併存させる。すべて鋭い皮肉にすると人格が冷たくなり、すべて無関係だと会話する価値がない。意味を受け止める短い一文と、脱線する二文目を基本単位にする。

## コード調査の結果

Emmy、Emmy II、工画堂、BASIC、source、ソース、解析、GitHubなどの組み合わせで公開情報を調査したが、ゲーム本体の公開ソース・利用許諾のある再実装・検証可能な逆アセンブル成果は確認できなかった。「存在しない」という結論ではない。

見つかったMAMEのXMLはディスクのサイズ・CRC/SHA1・動作条件を記したメタデータであり、ゲームソースではない。MAMEエミュレータのコードもEmmyのコードではない。これらを「原作コードを発見」と扱わない。

実データが入手できた段階では、読み取り専用の原本保管→ハッシュ照合→ディスク構造・ファイル一覧→文字列と辞書の抽出→固定入力での挙動記録→状態・記憶の差分比較、と進める。今回、ゲームバイナリの取得やリバースエンジニアリングは実施していない。試作は最初から独自コード。
